# Bitácora de uso de IA - BoliTax

Este archivo registra todo uso de herramientas de inteligencia artificial en el proyecto.
Las entradas se escriben en el momento de usar la herramienta, no al final.

## Reglas

- Copiar el prompt tal como se escribió, sin resumirlo.
- Nunca pegar en un prompt llaves de API, access tokens ni datos personales reales.
- Marcar el código asistido con un comentario: `// AI-assisted: see docs/AI_LOG.md #N`.
- Cada integrante puede ser llamado a explicar un bloque marcado como asistido por IA.
